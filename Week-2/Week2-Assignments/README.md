Week 2: Advanced JavaScript & Introduction to Backend
 Assignments Overview
1. Master of ES6 Array Methods
Eight comprehensive assignments (ass1.js - ass8.js) applying functional programming patterns to real-world datasets:
- Temperature Analyzer: Unit conversion and filtering.
- Online Course Processor: String manipulation and reduction.
- Student Performance: Grading systems and pass/fail logic.
- E-commerce Cart: Price calculations and stock management.
- Payroll Processor: Bonus applications and department filtering.
- Movie Streaming: Rating analysis and genre filtering.
- Bank Transactions: Balance calculation using complex reductions.

2. Modular Programming
- Todo Application (ass9.js): A multi-file task manager using ES Modules.
- E-commerce System (ass10.js): Complex dependency management between products, carts, discounts, and payments.

 3. OOP & Memory Management
- Library System (ass11.js): Implementation of ES6 Classes with encapsulation and method logic.
  -Cloning & Memory (ass12.js - ass15.js): 
  - Spread operator for modern object/array cloning.
  - Deep dive into Shallow Copy vs Deep Copy using structuredClone.

4. Asynchronous JavaScript
- Exam Portal Simulator (ass16.js) Using setTimeout for delayed evaluations.
- OTP Countdown Timer (ass17.js): Implementing real-time countdowns with setInterval and clearInterval.

 5. Backend Foundations (ass18)
- Setting up an Express server.
- Routing: Implementing modular APIs (user-api, product-api).
- Middleware: Custom request processing and logging.
- JSON Handling: Using express.json() for payload parsing.
