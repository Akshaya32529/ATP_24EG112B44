# Week 1: JavaScript Fundamentals & Array Operations

This repository contains the assignments completed during Week 1, focusing on core JavaScript concepts including conditional logic, functions, and advanced array manipulations.

## 🚀 Assignments Overview

| File Name | Description | Key Concepts |
| :--- | :--- | :--- |
| `bigOfTwo.js` | Finds the maximum of two numbers. | `if-else`, Ternary Operator |
| `bigOfThree.js` | Finds the maximum of three numbers. | `else-if` ladder, Nested Ternary |
| `sumofArray.js` | Calculates the total sum of an array's elements. | `for` loop, Accumulators |
| `smallOfArray.js` | Identifies the minimum value in an array. | Array Traversal, Comparison |
| `bigOfThreeFunc.js`| Function-based approach to find the largest of three numbers. | Named Functions, Parameters |
| `ass6.js` | Function to compute the sum of array elements. | Anonymous Functions, Scope |
| `ass7.js` | Implements a search algorithm for array elements. | Linear Search, Conditional Returns |
| `ass8.js` | Complex operations on an array of employee objects. | `splice`, Object Manipulation, Iteration |

---

## 🛠️ Detailed Breakdown

### 1. Basic Conditional Logic
- **Biggest of Two/Three**: Demonstrated using both standard control flow (`if/else`) and modern concise syntax (ternary operators).
- **Functions**: Abstracting logic into reusable components for cleaner code.

### 2. Array Manipulations
- **Traversals**: Using `for` and `for...in`/`for...of` loops to process data collections.
- **Aggregations**: Implementing sum and find-min algorithms from scratch.
- **Searching**: Custom search function to find values and handle "not found" cases.

### 3. Advanced Object & Array Operations (`ass8.js`)
This assignment showcases real-world data handling:
- **Insertion**: Using `.splice()` to inject new records at specific indices.
- **Deletion**: Finding an object by property (e.g., `name`) and removing it dynamically.
- **Updating**: Deeply nested updates (modifying a specific value within an array inside an object).
